## 真实 DeepSeek 天气 Demo 运行命令

真实密钥只通过环境变量注入，不能写入本文档或源码：

```powershell
$env:DEEPSEEK_API_KEY = "<YOUR_DEEPSEEK_API_KEY>"
$env:JAVA_HOME = (Resolve-Path ".tools\jdk-dist\jdk-21.0.12+8").Path
$env:MAVEN_OPTS = "-Dmaven.repo.local=.tools/m2 -Dtest=WeatherDemoAcceptanceTest -Dsurefire.failIfNoSpecifiedTests=false"

.\.tools\maven-dist\apache-maven-3.9.16\bin\mvn.cmd -pl oryxos-boot -am test
```

Demo Agent 的核心提示词：

```text
使用 Open-Meteo 查询上海（纬度 31.2304、经度 121.4737）的实时天气，
并根据实际温度、体感温度、降水和风速生成简洁、可执行的穿搭建议。
每次执行必须先调用 http_get 获取实时 JSON，禁止凭常识猜测天气；
收到 Tool 结果后，由大模型理解天气数据并生成最终中文建议。
```
