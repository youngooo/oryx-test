统一入口，受控执行

QUICK START

从一个 JAR 开始

当前版本是可运行的工程骨架。使用 JDK 21 和 Maven 构建，即可启动官网及基础健康检查接口。

i

OryxOS 处于早期开发阶段，核心 Agent 运行能力仍在持续实现，暂不建议用于生产环境。

terminal
$ git clone https://github.com/youngooo/oryx-test.git
$ cd oryx-test
$ mvn clean package
$ java -jar oryxos-boot/target/oryxos-boot-0.1.0-SNAPSHOT.jar

# http://localhost:8080
✓ OryxOS is running
